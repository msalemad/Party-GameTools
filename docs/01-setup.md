# Party-GameTools

## Requisitos a verificar

- Windows 11
- Visual Studio 2022
- Carga de trabajo **Desarrollo de la Plataforma universal de Windows**
- Carga de trabajo **Desarrollo de escritorio con C++** si se requieren APIs Win32
- SDK de Windows compatible con el Game Bar SDK
- Xbox Game Bar disponible en Windows
- Modo de desarrollador activo para pruebas locales

## Próximo paso

Instalar las cargas de trabajo necesarias y confirmar la versión de Visual Studio y Windows antes de generar el proyecto UWP definitivo.
