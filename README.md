# Party-GameTools

Widget táctico multipropósito para Microsoft Xbox Game Bar en Windows 11.

## Estado

Base inicial del proyecto. La implementación funcional se irá completando por fases:

1. Entorno y proyecto UWP
2. Vista principal modular
3. Temporizador y cronómetro
4. Alertas visuales y sonoras
5. Presets locales
6. Empaquetado MSIX y pruebas locales

## Tecnologías previstas

- Visual Studio 2022
- UWP / XAML
- Xbox Game Bar SDK
- MSIX
- Windows 11
